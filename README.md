Proyecto Power BI: limpieza de datos financieros con errores, análisis y visualización de métricas clave.

# Dashboard de Ventas y Finanzas

Dashboard interactivo creado en **Power BI** a partir de un dataset con inconsistencias financieras.  
El conjunto de datos fue limpiado, transformado y visualizado por mi **Jeimy Avila**,  
mostrando métricas clave de ventas, gastos y rentabilidad.  

📊 Incluye:
- Análisis de ingresos y pérdidas.
- Comparativa de rendimiento mensual.
- Visualización de tendencias financieras.
- Segmentación por departamento o región.

🧩 Archivo incluido:
- `Dashboard_BrosINC.pbit` → Plantilla de Power BI lista para reutilizar o conectar con nuevos datos.
